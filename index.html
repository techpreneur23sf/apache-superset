How this is measured

There is no cost metric on this page because this account does not report one. ACUs are the Enterprise billing unit; here acus_consumed is 0.0 on every session and GET /consumption/daily reports total_acus: 0.0, because the plan bills included quota plus on-demand credits, which the API does not expose per session. Rather than print a fabricated unit cost, effort is reported in the units the API does return: Devin's own session size classification (18×xs), 44 Devin messages, and wall-clock session time. The daily budget cap still binds — each dispatch reserves its class's per-session ACU limit up front instead of trusting an unmetered zero.
